# Воронка «100 Лидеров»

Дашборд отдела продаж по программе «100 Лидеров»: воронка, операторы (включая Chat2Desk), причины выбывания, источники, география, список кандидатов с умным поиском.

Адрес: https://rinatvisual.github.io/lp/

## Как пользоваться
1. Выгрузить кандидатов по вакансии «Лидерская программа» в Excel (.xlsx). Если больше 10 000 строк — двумя частями по дате добавления.
2. Открыть сайт, нажать «Открыть выгрузку» и выбрать файл (или сразу несколько — они склеятся, дубли уберутся).
3. Данные обрабатываются только в браузере и никуда не отправляются. Последний файл запоминается в этом браузере; «Забыть файл» убирает его.

Исходный код собирается в один файл `index.html` (React + TypeScript + D3).
